# TCK-1008: Job loghub_etl failed due to unauthorized access

## Report

The job loghub_etl failed with an unauthorized access error, preventing it from writing to the samples.tpch schema. This affected the ETL process, leading to incomplete data output.

Job: `loghub_etl` (hdfs) · failed run: https://dbc-xxxxxxxx-xxxx.cloud.databricks.com/?o=0000000000000000#job/1019584803253166/run/651255923794030

```
[UNAUTHORIZED_ACCESS] Unauthorized access:
PERMISSION_DENIED: User does not have CREATE TABLE on Schema 'samples.tpch'. SQLSTATE: 42501
UnknownException
hourly.write.mode("overwrite").saveAsTable(GOLD_TABLE)
```

## Timeline

- 2026-08-17 06:10 UTC — reported by dashboard owner
- First hypothesis: The job lacks necessary permissions to write to the target schema.
- Investigation: The engineer reviewed the error logs and found that the job identity did not have write privileges on the samples.tpch schema. This was confirmed by checking the user's permissions and the schema's ownership.
- 2026-08-17 08:10 UTC — resolved

## Root cause

The gold output targets samples.tpch, where the job identity lacks write privileges.

## Resolution

Write to a schema the job owns or request CREATE TABLE on the target.

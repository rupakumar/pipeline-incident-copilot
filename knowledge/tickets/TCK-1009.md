# TCK-1009: Job loghub_etl failed due to memory issues

## Report

The job ran out of memory during execution. The reporter observed that the debug_sample_rows parameter was set to a large value, leading to excessive data being collected in the driver.

Job: `loghub_etl` (spark) · failed run: https://dbc-xxxxxxxx-xxxx.cloud.databricks.com/?o=0000000000000000#job/1019584803253166/run/753170966345379


## Timeline

- 2026-08-23 06:10 UTC — reported by on-call data engineer
- First hypothesis: The job failed due to an unexpected data processing error.
- Investigation: The engineer reviewed the job logs and found that debug_sample_rows was set to 500M, which caused a massive sample to be collected in memory. This was the real cause of the memory exhaustion.
- 2026-08-23 09:10 UTC — resolved

## Root cause

debug_sample_rows=500M collects a huge sample to the driver, which runs out of memory.

## Resolution

Set debug_sample_rows to 0 (or a small number) and inspect samples with limit()/display instead of collect().
